個人開発 ・ PythonPersonal project, Python

RAG 文書Q&A APIRAG Document Q&A API

PDFやテキストをアップロードし、その内容について質問すると、根拠となる箇所を引用しながら回答をストリーミングで返すAPIです。検索拡張生成（RAG）の仕組みを、チャンク分割から評価まで自分で組み立てました。 Upload a PDF or text file, ask questions about it, and get a streamed answer that cites the passages it relied on. I built the full retrieval-augmented generation (RAG) pipeline myself, from chunking to evaluation.

工夫した点Design decisions

  • 500トークン／オーバーラップ50でチャンク分割し、検索精度と文脈の両立を図った（tiktokenで計測）500-token chunks with 50-token overlap, measured with tiktoken, to balance precision and context
  • 取得した文脈のみから回答し [1][2] 形式で引用、根拠が足りない場合は「分からない」と答えるプロンプト設計Grounded prompting: answer only from retrieved context, cite as [1][2], and say so when context is insufficient
  • 検索ヒット率と回答ヒット率を測る評価スクリプトを用意An evaluation script that measures retrieval hit rate and answer hit rate
  • 1クエリ約0.0005ドルとコストを試算し、規模拡大時の改善案（pgvector、リランカー、ハイブリッド検索）も整理Estimated cost at about $0.0005 per query, and documented what I'd change at scale (pgvector, a reranker, hybrid search)
  1. アップロード・解析Upload & parsepypdf
  2. チャンク分割Chunk500 / 50 tokens
  3. 埋め込み・保存Embed & storetext-embedding-3-small → ChromaDB
  4. 質問に近いチャンクを検索Retrieve top-k chunkstop_k 1–10
  5. 引用付き回答をストリーミングStream a cited answergpt-4o-mini, SSE

卒業研究 ・ チーム開発（4名）Graduation research, team of 4

裏声のスコアリングシステムFalsetto voice scoring system

裏声を録音すると、純度・力みの無さ・息漏れの少なさ・響きの豊かさ・安定性の5指標をAIが採点し、レーダーチャートと改善アドバイスを表示するボイストレーニング支援システムです。 A voice-training tool: record a falsetto note and the system scores it on five measures (purity, lack of strain, breathiness, resonance and stability), then shows a radar chart with tips to improve.

担当：音声データの前処理とPython実装My part: audio preprocessing and Python code

  • ノイズ除去 → 無音区間除去 → 0.5秒の安定区間抽出という前処理パイプラインを構築Built the preprocessing pipeline: noise reduction, silence removal, then extracting a stable 0.5-second segment
  • Parselmouthで22種の音響特徴量を取得し、学習用データセットを作成（H1-H2、HNR、CPP、Jitter、Shimmer など。うち14種を学習に採用）Extracted 22 acoustic features with Parselmouth (H1-H2, HNR, CPP, jitter, shimmer and more) to build the training dataset; 14 were used for training
  • データセットは計166件（公開データセット119件＋チーム独自録音47件）166 samples in total: 119 from a public dataset plus 47 recorded by the team

システム全体Whole system

  • 指標ごとに小規模なFNN（全結合ニューラルネット）を5つ並列で学習Five small feed-forward networks trained in parallel, one per measure
  • Flask＋SQLite3のサーバーと、録音から結果表示までのWebフロントエンドを統合Flask + SQLite3 backend with a web front end from recording to results
